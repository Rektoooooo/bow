Rebuild it

A design for your browser that follows Arc's structure, with Arc's measured values. Bow implements exactly this (src/main/autoArchive.ts).

  • Track use. Store lastActiveAt per unpinned tab. Set it when a tab is selected or left, and refresh visible tabs on a one-minute tick.
  • Sweep. Every few minutes, archive unpinned tabs older than the Space's threshold. Skip visible, audible and picture-in-picture tabs.
  • Start fair. On launch, measure from the later of lastActiveAt and the launch time.
  • Record why. Write an archive record with the reason and time, and keep it searchable.
  • Prune. Keep the newest 250 archive records.

Rebuild plan with REA

The order matters: cheap evidence first, decompiler time only for the handful of features whose rules you cannot see from outside.

  1. Map the bundleDone

    Bundle inventory, frameworks, Info.plist, the AppleScript dictionary and the bundled JSON configs. That is everything on this page.

  2. Fix Node and install READone

    REA needs Node 22.23.4+, 24.22.1+ or 26.12.1+; this Mac had 23.10.0. Homebrew here belongs to another macOS account, so Node 24.22.1 went into the home folder instead, checksum-verified from nodejs.org. REA 6.8.0 is registered with Claude Code and a test scan of Arc.app passed.

    npx -y rea-agents@latest setup --client claude_code --yes

  3. Set up a decompilerDone

    Ghidra 12.1.4 with Temurin JDK 21, both in the home folder and both checksum-verified. The Apple Silicon decompiler was built from Ghidra's bundled source, and a test decompile of Arc's Dock plugin returned Swift pseudocode. Ghidra through REA cannot open universal binaries, so analyze an arm64-only copy of each Arc binary:

    lipo -thin arm64 /Applications/Arc.app/Contents/MacOS/Arc -output Arc-arm64

  4. Read your own data model

    On the account where you use Arc, inspect StorableSidebar.json and the Chromium profile databases. This gives the exact shape of Spaces, folders, pinned tabs and split views.

  5. Trace the Binary features

    Ranked by how much each shapes the feel of Arc:

    • Auto-archive: answered from runtime evidence (see above); only itemsToExclude and the cleanup interval still need Ghidra
    • Command Bar ranking: source weights and duplicate rules
    • Peek triggers: which tabs and links open a Peek
    • Sidebar sync: how concurrent edits merge
    • Easel live captures: how regions refresh
    • Block list client: what it is for

  6. Build feature by feature

    Start with the sidebar, Spaces and the inset card, since everything else hangs off them. Then the Command Bar, Peek and Little Arc. Leave sync, sharing and AI for last.

Ground rules

  • Use REA to understand how a feature behaves, then write the implementation yourself.
  • Do not ship anything taken from the Arc bundle: code, icons, Lottie animations, sounds, onboarding videos, shaders, or rule lists such as tidy titles and the ad-block list. Make your own.
  • Give your browser its own name and look. Do not use Arc's name or logo.
  • REA's own disclaimer rules out copying proprietary code or assets. Analysis runs locally on your Mac.
